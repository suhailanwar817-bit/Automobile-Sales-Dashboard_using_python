# 🚗 Automobile Sales Statistics Dashboard

## 📖 Project Overview
The **Automobile Sales Statistics Dashboard** is an interactive web application built using **Python, Dash, and Plotly**. It analyzes historical automobile sales data to uncover how macroeconomic factors—such as recessions, GDP fluctuations, and unemployment rates—impact vehicle sales and advertising expenditures. 


## ✨ Key Features
* **Dual-Report System:** Users can dynamically switch between **"Yearly Statistics"** and **"Recession Period Statistics"** using an interactive dropdown menu.
* **Smart Callbacks:** The "Year" dropdown automatically disables when viewing recession data (which spans multiple years) and re-enables for specific yearly analysis.
* **KPI Summary Cards:** Displays real-time summary metrics (Average Sales, Total Sales, and Total Ad Spend) that update based on the user's selection.
* **Interactive Visualizations:** Features responsive, hoverable charts built with Plotly Express (line, bar, and pie charts).
* **Clean UI/UX:** Utilizes a responsive Flexbox layout ensuring charts sit side-by-side perfectly across different screen sizes.

## 🛠️ Tech Stack
* **Python** (Core logic)
* **Dash** (Web framework for interactive UI)
* **Plotly Express** (Data visualization)
* **Pandas** (Data manipulation and aggregation)

## 📊 Insights Generated
* **Recession Impact:** Visualizes the drastic drop in sales during recession periods across different vehicle types.
* **Unemployment Correlation:** Highlights how rising unemployment disproportionately affects luxury/sports cars compared to essential/budget vehicles.
* **Advertising ROI:** Analyzes how advertising budgets are distributed across vehicle types during economic downturns.
* **Seasonality:** Tracks monthly sales trends to identify peak purchasing periods.
